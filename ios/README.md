# Sky Scooter — iOS

The iPhone version reuses the game in `app/src/main/assets/game/` unchanged.
`ios/` holds only a small Swift shell (WKWebView) that provides the same
`window.AndroidBridge` API as Android: AdMob + UMP consent, haptics, run
snapshot and the 3D visual kit.

No Mac needed: the Xcode project is generated by XcodeGen and built by
GitHub Actions (`.github/workflows/ios.yml`) on every push to the `ios` branch.

## Install on your iPhone (free, no Apple Developer account)

1. GitHub → **Actions** → latest **iOS build** run → download **SkyScooter-ipa**, unzip it.
2. On Windows install **iTunes** (Apple version, not Microsoft Store) and **Sideloadly**.
3. Plug the iPhone in with USB, open Sideloadly, drag in `SkyScooter-unsigned.ipa`,
   enter your Apple ID, click **Start**.
4. On the iPhone:
   - Settings → Privacy & Security → **Developer Mode** → On (restart).
   - Settings → General → **VPN & Device Management** → your Apple ID → **Trust**.

A free Apple ID signature lasts 7 days; repeat step 3 to renew.

## Before publishing on the App Store

- Apple Developer account ($99/year).
- In AdMob, add an **iOS app** for Sky Scooter and replace the three test ids in
  `ios/SkyScooter/Info.plist` (`GADApplicationIdentifier`, `SSInterstitialAdUnit`,
  `SSRewardedAdUnit`). The current values are Google's public test ids.
- Add `app-ads.txt` coverage for the iOS app (same file on salahlouffidi.github.io).
- Signing + TestFlight upload step in the workflow (needs the account).
