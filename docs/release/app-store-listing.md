## App Privacy ("nutrition label")

Data collected by the Google Mobile Ads SDK (check against Google's current
"Prepare for Apple's App Store data disclosure requirements" page before submitting):

| Data type | Collected | Purpose | Linked to user | Tracking |
|---|---|---|---|---|
| Identifiers → Device ID | Yes | Third-Party Advertising, Analytics | No | No |
| Usage Data → Product Interaction | Yes | Third-Party Advertising, Analytics | No | No |
| Usage Data → Advertising Data | Yes | Third-Party Advertising, Analytics | No | No |
| Diagnostics → Crash Data, Performance Data | Yes | Analytics | No | No |
| Location → Coarse Location (from IP) | Yes | Third-Party Advertising, Analytics | No | No |

"Tracking: No" holds because the app does not request App Tracking Transparency,
so the advertising identifier (IDFA) is never available to the SDK.
The game itself stores progress only on the device.
